This document aims to collect areas in which Clearinet is improved over Telerik's (now defunct) Fiddler Classic.

# Textransformer:
- supports [CBOR](https://cbor.io/)
- supports JWT Token decoding
- supports Epoch decoding
- offers simple "Copy to clipboard"
- is extensible via script (`BindTextCodec`)

# More Copy Helpers
- Copy for LLM/AI
- Copy PowerShell/JSFetch

# UI
- Find panel in page
- Long-running operation UI
- Dark mode support (needs lots of work)

# Images
- JXL support
- AVIF support

# API
- BindUIButton accepts a tooltip (e.g. BindUIButton('ButtonText', 'ButtonTooltip') )
- RulesOption can target a :String field

# about:config
- Supports tearoff
- Highlights changed preferences
